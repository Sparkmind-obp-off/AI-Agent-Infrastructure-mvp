# 4. CYCLE 008 NEW METHODOLOGY

## PRIMARY STRATEGY
### CONTROLLED ABSTRACT COMPOSITE MARKS + NEGATIVE-SPACE PHONETICS

The goal is to construct names from **neutral phonetic units** without borrowing recognizable religious, mythological, geographic, surname, scientific, pharmaceutical, or culturally loaded roots.

Use 2–3 deliberately selected abstract sound units.

The units should be:
- semantically light or meaningless;
- pronounceable;
- visually distinctive;
- stable in Indonesian and English;
- not obviously derived from one identifiable natural language;
- not pseudo-Norse/Nordic;
- not pseudo-Latin/Greek;
- not Japanese/Korean/Indian/Sanskrit-coded;
- not Slavic/medieval/fantasy-coded;
- not obviously surname-like.

### Structural target

Generate approximately **70–100 raw candidates**.

Preferred range:
- 6–9 letters;
- 2–4 syllables;
- 2–3 abstract phonetic units;
- clean consonant-vowel balance;
- no obligatory suffix;
- no obvious semantic root;
- pronounceable on first hearing;
- spelling reasonably recoverable after hearing.

Use controlled phonetic patterns such as:
- CV-CVC-CV
- CVC-CV-CVC
- CVCC-CVC-V
- CVC-CVC
- CV-CVCC-CV

These are structural examples only.

Do NOT mechanically repeat a pattern.

The purpose is **abstract distinctiveness without artificial weirdness**.
