# 1. CYCLE 006 OBJECTIVE

Cycle 005 established that naming-space saturation is **architecture-independent** across:

- short coined marks;
- two-word/phrasal brands;
- short real-word/lexical marks.

Therefore Cycle 006 MUST NOT simply generate another batch of short startup-style names.

The new strategy is:

> **RARE NEUTRAL MULTI-MORPHEME CONSTRUCTION + FIRST-PARTY CLEARANCE-FIRST RESEARCH + HISTORICAL SHORTLIST AUDIT**

The goal is to explore a deliberately less crowded phonetic architecture while preserving the project's permanent constitution:

**PURE NEUTRALITY → BRANDABILITY → PREMIUM MODERNITY → INFRASTRUCTURE CREDIBILITY → COLLISION DESTRUCTION → CLEARANCE GATE**

# 4. CYCLE 006 NAMING ARCHITECTURE

Do NOT use the Cycle 004/005 dominant pattern:

- simple 2-syllable startup mark;
- simple CVCV invented word;
- generic concept + infrastructure noun;
- short premium English dictionary word;
- Italian/Latin feminine/diminutive endings;
- obvious "-AI", "-Tech", "-Labs", "-Cloud", "-Systems", "-Digital", "-Agent", "-OS".

### PRIMARY FAMILY — RARE MULTI-MORPHEME COINED MARKS

Generate approximately:

**60–80 raw candidates.**

Preferred structural territory:

- 7–10 letters;
- 3–4 syllables;
- 2–4 neutral phonetic/morphemic units;
- uncommon but pronounceable consonant transitions;
- stable Indonesian + English pronunciation;
- visually clean;
- not fantasy-coded;
- not pseudo-Nordic/medieval-coded merely for uniqueness;
- not obviously Latin/Greek religious/scientific terminology;
- not feminine-fashion-coded;
- not pharmaceutical-coded;
- not surname-like where avoidable.

Examples of STRUCTURE ONLY, NOT CANDIDATES:

- CV-CVC-CV
- CVC-CV-CVC
- CVCC-CV-CVC
- CVC-CVC-CV

Do not copy these examples into candidate generation.

The objective is **phonetic rarity without cultural weirdness**.
