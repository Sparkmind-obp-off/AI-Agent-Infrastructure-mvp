# 4. PRIMARY METHODOLOGY
## CONTROLLED TWO-WORD NEUTRAL SEMANTIC PAIRS

Generate names composed of **two ordinary, neutral, internationally understandable words**.

The words should form a conceptual pair without literally describing the product.

Examples of semantic territories to explore:

- structure + movement
- field + connection
- layer + motion
- signal + structure
- frame + continuity
- fabric + direction
- source + motion
- plane + connection
- line + structure
- core + field
- pattern + motion
- space + relay
- path + structure
- form + signal
- base + motion

These are territories, NOT candidate names.

Do not simply combine the obvious infrastructure nouns listed in previous prompts.

The pair should have:
- low semantic loading;
- neutral everyday meaning;
- strong visual identity;
- easy pronunciation;
- easy spelling;
- credible enterprise sound;
- enough abstraction to become a master brand;
- room for a descriptor such as Runtime, SDK, Cloud, or API.
