# 9. DISTINCTIVENESS GATE

Compound names create a new danger: being descriptive rather than conflicted.

For each candidate classify:

**DISTINCTIVE**
- memorable;
- semantically coherent;
- not merely category description.

**SEMI-DESCRIPTIVE**
- understandable but still brandable.

**DESCRIPTIVE**
- merely states what the company does.

**GENERIC**
- cannot function as a distinctive master brand.

Reject GENERIC.

Do not automatically reject every SEMI-DESCRIPTIVE candidate; test the full mark.
