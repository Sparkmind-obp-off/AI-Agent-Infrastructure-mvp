# 6. NEGATION CATEGORIES

Every generated candidate must be tested upstream against these categories.

## A. Indonesian

Reject or heavily downgrade if the candidate:

- contains a recognizable Indonesian word with undesirable meaning;
- sounds like common slang;
- sounds like a profession/title;
- sounds medical;
- sounds vulgar/offensive;
- creates an embarrassing phrase;
- is easily segmented into Indonesian words with strong semantic baggage.

Explicitly test:

- KBBI;
- common Indonesian slang;
- common regional-language leakage where obvious;
- syllable segmentation.

## B. English

Check:

- ordinary dictionary words;
- common technical words;
- slang;
- offensive meanings;
- strong consumer meanings;
- common business terms.

## C. Major European languages

At minimum where evidence is accessible:

- Spanish;
- Portuguese;
- French;
- German;
- Italian;
- Dutch;
- Polish;
- Czech/Slovak;
- Croatian/Serbian/Bosnian;
- Hungarian;
- Romanian.

Do not require exhaustive linguistic scholarship. The purpose is to catch obvious high-signal collisions.

## D. Asian language/name leakage

Check obvious collisions in:

- Japanese;
- Korean;
- Chinese romanization;
- Hindi/Sanskrit-derived names;
- common Southeast Asian names/words.

Do not over-eliminate merely because a weak surname exists. Identity strength matters.

## E. Surname / personal-name leakage

Reject when the candidate is strongly recognized as:

- a common surname;
- a common given name;
- a famous family/clan;
- a strong personal identity.

A rare person sharing the spelling is not automatically terminal.

## F. Geography

Reject when it is strongly associated with:

- a city;
- region;
- country;
- landmark;
- ethnic/geographic identity;

unless the association is weak and non-dominant.

## G. Medical / pharma

Check:

- WHO INN stems;
- drug names;
- medical-device brands;
- clinical terminology;
- pharmaceutical companies.

This is a high-priority negative category because Cycle 015 repeatedly encountered it.

## H. Technical identifier leakage

Check:

- existing APIs;
- SDKs;
- packages;
- developer tools;
- protocols;
- libraries;
- infrastructure systems;
- cloud products.

## I. Company / product identity

Check active:

- startups;
- SaaS;
- enterprise software;
- infrastructure vendors;
- agencies;
- consumer brands.

Same-category and adjacent technology identity should be treated as high severity.

## J. Fiction / fantasy / mythology

Avoid:

- fantasy franchise terms;
- famous fictional entities;
- gaming identities;
- mythology-coded names;
- invented creature names;
- occult/spiritual baggage.

## K. Constructed-language words

Check major constructed/international auxiliary language evidence where obvious.

Cycle 015 demonstrated that a seemingly invented name can be a real Ido/Esperanto word.

# 18. ADVERSARIAL DESTRUCTION

For every surviving candidate ask:

1. What single fact would make this name unusable?
2. Is there a hidden lexical meaning?
3. Is there a surname collision?
4. Is there a place collision?
5. Is there a medical/pharma collision?
6. Is there a technical identifier?
7. Is there a same-category company?
8. Is there a near-clone?
9. Is there a phonetic mishearing?
10. Is there an embarrassing Indonesian interpretation?
11. Is there a major-language negative meaning?
12. Is there a fictional/fantasy identity?
13. Does a search result dominate the name?
14. Would a skeptical CTO reject it?
15. Does it still work if AI becomes commodity infrastructure?

A terminal answer means reject immediately.
