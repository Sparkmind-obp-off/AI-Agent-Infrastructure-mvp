# Vestren Roadmap

## Phase 0 — Foundation
Architecture, contracts, security model, provider policy, product documentation and final brand lock.

## Phase 1 — Runtime
Workers + Hono + agent runtime + state + D1.

## Phase 2 — Tools
MCP and provider adapter layer.

## Phase 3 — Execution
E2B integration, artifacts, limits and audit.

## Phase 4 — Product
UI, project/agent management, observability and onboarding.

## Phase 5 — Validation
Real use cases, reliability testing, free-tier measurement, cost validation.

## Phase 6 — Expansion
BYOK providers, additional execution providers, billing and production hardening.

The Vestren brand is final. No further naming cycle is part of the roadmap.
