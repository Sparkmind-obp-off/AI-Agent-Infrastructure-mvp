## 4. HARD LESSONS FROM CYCLE 001

Cycle 001 tested 117 candidates and produced zero survivors.

Do not repeat its failed method.

### Terminal lessons

1. Short dictionary nouns are heavily saturated.
2. AI-agent/MCP/observability/execution nouns are particularly crowded.
3. A phonetic collision with a major technology brand is a real collision.
4. `-yn`, `-yx`, `-ryn`, `-trin`, `-stra`, `-adin`, `-ell`, `-oc`, `-ris`, `-tin`, and similar fantasy-tech constructions are now high-risk.
5. Indonesian pronunciation must be tested before deep research.
6. Search-sparse does not mean trademark-clear.
7. A GitHub/software identity in the same category is sufficient to kill a candidate.
8. A candidate that sounds like an incumbent must be killed rather than rationalized.
9. Do not select the least-bad name merely to end the cycle.
10. Every new cycle must materially change the generation/search method.

## 6. INDONESIAN PHONETIC FILTER — UPSTREAM

Every generated candidate must first pass an Indonesian pronunciation test.

For each candidate:

1. Read it as an Indonesian speaker would naturally read it.
2. Generate at least 3 plausible Indonesian pronunciations.
3. Test for accidental similarity to:
   - vulgar expressions
   - insults
   - sexual terms
   - religiously sensitive terms
   - common slang
   - common consumer words
   - `sialan`
   - `silikon`
   - `setan`
   - `bego`
4. Test whether the spelling causes obvious pronunciation ambiguity.
5. Test whether an Indonesian buyer can repeat the name after hearing it once.
6. Kill candidates with material risk.

Do this **before** spending deep-search effort.

## 7. CLEARANCE-GAP-FIRST METHOD

Do not begin with random name generation.

First construct a **saturated-territory map** covering:

- AI agent platforms
- agent runtimes
- agent orchestration
- MCP infrastructure
- AI execution/sandbox
- AI observability
- developer infrastructure
- infrastructure APIs
- workflow/runtime platforms
- model infrastructure
- distributed systems
- cloud developer tooling
- security/control planes
- infrastructure marketplaces
- adjacent AI developer startups

Identify naming patterns and occupied semantic/phonetic zones.

Then identify **gaps**.

A gap means a naming territory where:

- major category incumbents are sparse,
- direct GitHub/software collisions are sparse,
- phonetic neighborhoods are not dominated,
- the word/construction can support enterprise infrastructure,
- Indonesian pronunciation is clean,
- the name can extend to `[NAME] Runtime`, `[NAME] SDK`, `[NAME] Gateway`, `[NAME] Cloud`, `Built on [NAME]`.

Generate only inside those gaps.
