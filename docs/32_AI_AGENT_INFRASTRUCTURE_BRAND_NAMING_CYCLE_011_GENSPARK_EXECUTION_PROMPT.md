# 5. MATERIAL METHODOLOGY SHIFT

Cycle 011 must reverse the normal order.

Previous cycles mostly followed:

GENERATE → SEARCH → CLEARANCE

Cycle 011 must follow:

CLEARANCE CONSTRAINTS → REGISTRY-FIRST FILTER → CONTROLLED GENERATION → IMMEDIATE DESTRUCTION → PROFESSIONAL HANDOFF

Before generating names, establish the clearance constraint map from available authoritative or high-quality sources.

Identify:
- saturated trademark morphology;
- saturated software/company name families;
- pharma morphology;
- common surname structures;
- geographic structures;
- fantasy/fiction structures;
- high-conflict phonetic corridors;
- naming architectures with repeated collisions in Cycles 001–010.

The objective is to generate only a very small set inside the remaining defensible space.

# 15. PRIMARY ASSOCIATION + FIVE-SECOND TEST

Classify primary association:

- CLEAN
- MOSTLY CLEAN
- MIXED
- DOMINATED
- CONFLICTING

Ask:

> What existing identity would a neutral developer or CTO think of first?

Then ask:

> What does a neutral observer think this is after five seconds?

Possible interpretations:
- software/platform;
- company;
- person;
- place;
- medicine;
- consumer product;
- fashion/luxury;
- fiction;
- generic technical phrase;
- abstract master brand.

A dominant unrelated identity is a rejection signal.
