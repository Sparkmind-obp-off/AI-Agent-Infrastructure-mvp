## 9. New methodological change

Cycle 015: **generate → deep-search → discover the negation**. Every candidate spent the full destruction budget before failing.

Cycle 016: **generate → early-negate through lexicon/company/pharma/gaming screen → spend deep-clearance budget only on survivors**.

Concretely, Cycle 016 shifted the first evidence action from adversarial destruction (single-candidate, sequential) to a **batched pre-screen** on ~50 candidates in parallel using structured web queries stratified by negation category. Deep destruction was reserved for whichever candidates emerged from pre-screen with SEARCH-CLEAN or WEAK-COLLISION status. This delivered ~10× throughput vs Cycle 015 for the same wall-clock budget and produced the same "no forced winner" conclusion honestly rather than by exhaustion.
