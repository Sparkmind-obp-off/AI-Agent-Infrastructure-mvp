## 3. TRACK A — ACQUISITION-FIRST
Scout existing naming assets rather than assuming another invented mark is the answer.
Look for parked/dormant domains, lightly used coined brands, inactive software/project names, publicly listed domains/brands for sale, and existing neutral marks with weak current use.
Prefer 5–10 letter single-word or compact two-word assets, neutral, pronounceable in Indonesian/English, infrastructure-compatible, and scalable to Runtime/SDK/API/Gateway/Cloud/Console/Enterprise.
Do not contact owners, represent the project as buyer, or estimate willingness to sell.

Evidence states:
ACQUISITION_SIGNAL_VERIFIED — authoritative/public marketplace explicitly indicates for sale.
ACQUISITION_SIGNAL_SEARCH_OBSERVED — dormancy/parking/inactivity observed without sale signal.
ACTIVE_OWNER — active use.
CONFLICT — dominant identity.
UNKNOWN — insufficient evidence.
Never convert SEARCH_OBSERVED to AVAILABLE.

Sources where accessible: Sedo, Afternic, Atom, GoDaddy Auctions, Namecheap marketplace, Flippa, other reputable marketplaces, official company registries, GitHub, npm, PyPI, crates.io, Docker Hub.
Investigate historical use, prior company/product, project history, domain history where observable, redirects, spam/reputation/security signals, trademark history, social identity, and current commercial use.
Funnel: 50–100 observed → 20 surface → 8–12 deep → maximum 3 serious acquisition/clearance candidates.
Do not pad. If no credible acquisition signal exists, state TRACK A RESULT — NO VERIFIED ACQUISITION SIGNAL.

## 4. TRACK B — CLEARANCE-CONSTRAINED NEW NAME
Generate only 15–25 candidates.
Architecture: controlled abstract marks; 6–10 letters; 2–4 syllables; semantically light; no obvious single-language origin; Indonesian + English pronounceable; hearing-to-spelling reasonably recoverable; no forced suffix family; no pharma/fantasy/surname morphology; no mythology; no generic infrastructure noun; no obvious technical term.
Optimize: neutrality → clearance potential → phonetic stability → master-brand credibility.
Funnel: 15–25 raw → 5–8 surface → 2–4 deep → maximum 1–2 professional-clearance candidates.
Hard-gate failure = REJECT. No rescue variants.
